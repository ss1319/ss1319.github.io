📁 一、认识网站文件结构

✏️ 二、如何修改文字内容

方法1：用记事本打开修改（最简单）

  1. 右键点击 .html 文件 → 打开方式 → 记事本
  2. Ctrl+F 搜索你要改的文字
  3. 直接改成你想要的内容
  4. Ctrl+S 保存，刷新浏览器即可看到效果
📝 示例：修改AI介绍文字

打开 pages/ollama.html，找到这一段：

复制 <h3>Ollama 是什么？</h3> <p>Ollama 是一个本地运行的大模型工具...</p>

把中间的文字改成你想要的，比如：

复制 <h3>Ollama 是什么？</h3> <p>这是我自己写的介绍文字...</p>

方法2：用VS Code修改（推荐，有高亮）

下载VS Code（免费），把文件夹拖进去就能编辑，修改后自动保存。

⚠️ 注意：< > / 这些符号不要删，它们是网页代码标签，删了网页就乱了。只改标签中间的文字。

➕ 三、如何新增一个AI页面

  1. 复制一个现有的AI页面，比如 pages/doubao.html
  2. 改个新名字，比如 pages/myai.html
  3. 打开新文件，修改里面的标题、介绍、链接
  4. 打开首页 index.html，在对应分类里加一行链接

首页加链接的代码：

复制 <a class="card" href="pages/myai.html"> <div class="card-icon">🤖</div> <h3>我的AI</h3> <p>这是我的AI介绍</p> </a>
💡 把上面的代码复制到 index.html 里对应分类的卡片列表中即可。

🔗 四、如何修改链接地址

每个AI页面里都有官网地址、接口文档等链接。修改方法：

找到链接代码：

复制 <a href="https://原来的网址" target="_blank">点我访问官网</a>

替换成新链接：

复制 <a href="https://你的新网址.com" target="_blank">点我访问官网</a>
💡 记住：只改引号里的网址，其他代码不要动。

🎨 五、如何修改颜色和样式

所有样式都在 assets/css/main.css 文件里。

常用颜色代码：

复制 主色（金色）: #d4a017 或 #f4d03f 背景色: #fff8e7（浅金） 文字色: #333333（深灰） 按钮色: linear-gradient(135deg, #d4a017, #f4d03f)

打开 main.css，搜索 background 或 color，改成你想要的颜色即可。

📤 六、如何上传修改到GitHub

方法1：GitHub Desktop（你已安装）

  1. 打开 GitHub Desktop 3.5.4
  2. 左上角选择仓库 aiss
  3. 左边会显示你修改过的文件
  4. 左下角写个说明（比如"更新页面"）
  5. 点 "Commit to main" 按钮
  6. 然后点右上角 "Push origin" 按钮
  7. 等1分钟，刷新网页就能看到新版
📸 上传步骤图解（点击展开）

第1步：打开GitHub Desktop，看到左侧Changes列表里有你改的文件

第2步：左下角Summary框里写"更新了XX页面"

第3步：点蓝色的 "Commit to main" 按钮

第4步：点右上角 "Push origin" 上传到GitHub

第5步：等1分钟，打开 https://ss1319.github.io/aiss/ 刷新看效果

💡 如果你改了 xgsc.html（在ss1319.github.io仓库），要在GitHub Desktop左上角切换到那个仓库再上传。

🔑 七、如何配置AI接口Key

在网页里调用AI接口，需要在JavaScript代码里填入你的API Key。

通用模板代码：

复制 // 调用AI接口的通用代码 async function callAI(prompt) { const response = await fetch('https://api.你的AI网址.com/v1/chat/completions', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer 你的API_KEY填这里' }, body: JSON.stringify({ model: '模型名称', messages: [{role: 'user', content: prompt}] }) }); const data = await response.json(); return data.choices[0].message.content; }

各AI的Key获取地址：

  • OpenAI: https://platform.openai.com/api-keys
  • DeepSeek: https://platform.deepseek.com/api_keys
  • 智谱: https://open.bigmodel.cn/usercenter/apikeys
  • 月之暗面: https://platform.moonshot.cn/console/api-keys

📱 八、如何把AI嵌入到exe或apk

做成exe桌面程序：

用 Electron 或 Tauri 把网页打包成exe：

复制 # 用Electron打包（示例） npm init -y npm install electron --save-dev # main.js 里写： const { app, BrowserWindow } = require('electron'); function createWindow() { const win = new BrowserWindow({ width: 1200, height: 800 }); win.loadFile('index.html'); // 你的网页 } app.whenReady().then(createWindow);

做成apk手机应用：

用 Capacitor 或 Cordova 把网页打包成apk：

复制 # 用Capacitor打包（示例） npm init @capacitor/app npx cap add android npx cap copy npx cap open android # 用Android Studio编译出apk
💡 嵌入后，网页里的AI接口调用就是在exe/apk内部直接运行，不需要浏览器。

❓ 九、常见问题解答

Q: 上传后网页没变？

等1-2分钟GitHub Pages自动构建。如果还没变，按 Ctrl+F5 强制刷新清除缓存。

Q: 网页打开404？

检查文件名是不是英文。中文文件名在GitHub Pages上经常404，全部用英文短名。

Q: 想改客服面板的二维码？

替换 assets/img/zsm.png（赞赏码）和 assets/img/wxsy1349.png（公众号码），文件名保持不变即可。

Q: 如何加快网页打开速度？

GitHub Pages在国内慢是正常的。可以把网站部署到EdgeOne Pages（腾讯云免费CDN），国内打开快很多。
