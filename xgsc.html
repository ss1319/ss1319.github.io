认识网站文件结构
▼

📁 网站文件都在哪里？

你电脑上的网站源码全部放在这个文件夹：

E:\000000已设计好的完整HTML源码\AI配置教程\

文件夹结构说明：

  • index.html — 首页（目录页）
  • pages\ — 每个AI一个独立页面
  • assets\css\main.css — 全站样式（颜色、布局）
  • assets\js\main.js — 全站交互（搜索、客服面板）
  • assets\img\ — 所有图片（二维码、截图）
[示意图：文件夹结构截图]

如何修改文字内容
▼

✏️ 用什么工具改？

用任何文本编辑器都可以改，推荐用记事本或VS Code：

  • 右键文件 → 打开方式 → 记事本
  • 或用VS Code打开（推荐，有高亮）

🔍 找到要改的位置

比如要改首页标题：

<!-- 这是首页标题 -->
<h1>全国中文AI大全</h1>

把"全国中文AI大全"改成你想要的文字即可

改完按 Ctrl+S 保存，然后上传到GitHub就生效了。

💡 小技巧：在记事本里按 Ctrl+F 可以搜索关键词快速定位要改的位置。

如何修改颜色和样式
▼

🎨 修改主色调

打开 assets\css\main.css 文件，找到顶部变量：

:root {
  --gold: #d4a017;        /* 金色主色 */
  --gold-light: #f4d03f;  /* 浅金色 */
  --bg-dark: #1a1a2e;     /* 背景深色 */
}

把颜色值改成你喜欢的就行，比如改成蓝色：

--gold: #48dbfb;
--gold-light: #74b9ff;

🔡 修改字体大小

在main.css里搜索 font-size，找到对应位置修改数字即可：

  • 正文：18px（默认，不要改小）
  • 标题：最大32px
  • 按钮：16px

如何新增一个AI页面
▼

📄 复制一个现有页面

1. 进入 pages\ 文件夹

2. 随便复制一个现有的AI页面，比如复制 ollama.html

3. 重命名为新AI的英文名，比如 newai.html

4. 双击打开，把里面的文字改成新AI的介绍

🔗 在首页添加入口链接

打开 index.html，找到AI卡片列表，复制一个卡片代码：

<a href="pages/newai.html" class="card">
  <h3>新AI名称</h3>
  <p>新AI简介</p>
</a>

📤 上传两个文件

把 pages\newai.html 和 index.html 都上传到GitHub仓库。

⚠️ 文件名必须用英文，不要用中文，否则链接会404。
5
如何上传文件到GitHub（最常用）
▼

🖥️ 方法一：用GitHub Desktop（推荐）

1. 打开桌面上的 GitHub Desktop

2. 左上角选择仓库 aiss

3. 修改的文件会自动显示在 Changes 列表里

4. 左下角写一句话说明改了什么，点 Commit to main

5. 点顶部 Push origin 按钮上传

6. 等1-2分钟，刷新网页就生效了

[示意图：GitHub Desktop界面]

🌐 方法二：用GitHub网页上传

1. 打开 https://github.com/ss1319/aiss

2. 点右上角 Add file → Upload files

3. 把本地文件拖进去

4. 点底部绿色按钮 Commit changes

5. 等1-2分钟生效

[示意图：GitHub网页上传界面]
⚠️ 注意：上传后要等1-2分钟GitHub Pages才会更新，不要以为没生效就重复上传。

如何替换图片
▼

🖼️ 替换二维码或截图

1. 把新图片放到 assets\img\ 文件夹

2. 保持文件名和原来一样（比如 zsm.png），直接覆盖

3. 上传到GitHub

4. 强制刷新网页：按 Ctrl+Shift+R（清除缓存刷新）

💡 为什么要Ctrl+Shift+R？因为浏览器会缓存旧图片，强制刷新才能看到新的。
7
常见问题解答
▼

❓ 上传后网页没变？

回答：GitHub Pages需要1-2分钟构建，按 Ctrl+Shift+R 强制刷新即可。

❓ 打开显示404？

回答：文件名用了中文，改成英文重新上传。比如"教程.html"改成 guide.html。

❓ 图片不显示？

回答：检查图片路径是否正确，必须以 assets/img/ 开头，区分大小写。

❓ 客服面板不见了？

回答：新建页面时要复制客服面板代码（在body最后面），不要漏掉。
